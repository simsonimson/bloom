# ADR-011: Code-Signing über SignPath Foundation

- Status: angenommen
- Datum: 2026-11-26

## Kontext

Unsignierte Launcher lösen SmartScreen- und Antivirus-Warnungen aus.

## Entscheidung

Bewerbung bei der SignPath Foundation nach dem ersten öffentlichen Beta-Release. Release-Builds entstehen ausschließlich in GitHub Actions.

## Konsequenzen

Kostenlos. Herausgeber im Zertifikat ist die SignPath Foundation. Bis zur Aufnahme gibt es unsignierte Betas.
