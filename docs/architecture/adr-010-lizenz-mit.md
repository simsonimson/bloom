# ADR-010: Lizenz MIT

- Status: angenommen
- Datum: 2026-11-26

## Kontext

Bloom soll Open Source sein und Code aus MIT-Projekten nutzen können.

## Entscheidung

Das gesamte Repository steht unter MIT. Übernommener Fremdcode wird in THIRD-PARTY-NOTICES.txt geführt. Kein Code aus GPL-Projekten (z. B. Fishstrap).

## Konsequenzen

Kompatibel mit bloom3d.py und Bloxstrap. OSI-anerkannt, Voraussetzung für SignPath.
